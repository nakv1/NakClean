## О проекте

**NakClean** - это аналог CCleaner / BoosterX / WizTree / Recuva, написанный с нуля на **C# / .NET 8 + WPF**.
Главный принцип - **честность**: никаких «ускорителей ОЗУ» и фейковых твиков. Каждое действие либо реально освобождает место, либо реально меняет настройку Windows - и программа честно говорит, какой будет эффект.

Премиальный тёмно-золотой дизайн (есть и тёплая светлая тема), полная локализация **RU / EN**.

## ⬇ Скачать

1. Откройте страницу **[последнего релиза](https://github.com/nakv1/NakClean/releases/latest)**.
2. Скачайте **`NakClean.exe`** - это один файл, устанавливать ничего не нужно (.NET уже внутри).
3. Запустите. Windows спросит права администратора - они нужны для очистки, твиков и обслуживания.

Рядом с программой лежит файл **`NakClean.exe.sha256`** - по нему можно убедиться, что файл скачался целым и не подменён.

## ✨ Возможности

| Раздел | Что делает |
|---|---|
| **Обзор системы** | Приветствие и живой монитор: CPU, ОЗУ, видеокарты (загрузка / температура / VRAM), диски, батарея + сводка по системе. Если диск почти заполнен - подсказка, куда ушло место |
| **Проверка ПК** | Балл здоровья 0-100 и понятные вердикты: память, итог теста ОЗУ, место на дисках, SMART, Защитник, драйверы, время работы, мусор |
| **Очистка** | Мусор системы и браузеров, кэши программ (Discord / Spotify / Teams / Steam…), следы, корзина - с честным подсчётом места |
| **Оптимизация** | Реально работающие твики с честными метками эффекта, профили (Игровой / Тихий / Сбалансированный), точка восстановления, журнал изменений + откат всего разом |
| **Обслуживание** | SFC, DISM RestoreHealth, очистка WinSxS, дефрагментация / оптимизация дисков, тест ОЗУ с показом итога последней проверки |
| **Реестр** | Поиск и исправление битых записей. Перед каждым изменением - резервная копия, на вкладке «Резервные копии» любую можно восстановить в один клик |
| **Запуск** | Автозагрузка, запланированные задачи, службы, контекстное меню. Перед удалением сохраняется копия записи, ярлыки уходят в корзину |
| **Удаление программ** | Деинсталляция, восстановление, переименование, «убрать из списка» (с резервной копией), приложения из Microsoft Store |
| **Поиск файлов** | Анализ диска за секунды через чтение NTFS MFT (как WizTree): дерево папок, типы файлов, список крупнейших файлов, карта диска (treemap). «Удалить в корзину» прямо из списка - системные файлы защищены |
| **Восстановление** | Поиск и возврат удалённых файлов с NTFS-дисков с честным шансом восстановления (учитываются перезапись, фрагментация и TRIM на SSD). Восстановление только на другой диск, чтобы не затереть данные |
| **Диагностика** | Здоровье дисков (SMART для NVMe и SATA: температура, часы работы, износ), батарея (износ / заряд / паспорт), анализ времени загрузки, паспорт ПК (HTML) |

## 🔄 Обновления

- Программа сама проверяет новую версию на GitHub и показывает карточку со списком изменений.
- **Обновление в один клик:** новая версия скачивается, сверяется по SHA256 и заменяет старую, программа перезапускается сама.
- После обновления - окно **«Что нового»**; его можно открыть и в «О программе».
- Запускается только одна копия программы: повторный запуск просто показывает уже открытое окно.

## 🛡 Принципы

- **Без плацебо** - отброшены все «фейковые» оптимизации; остались только реально работающие.
- **Прозрачность** - перед удалением / изменением видно, что и зачем.
- **Всё можно вернуть** - резервные копии реестра, автозапуска и списка программ, откат твиков, удаление файлов - в корзину.
- **Минимум зависимостей** - WMI и Win32 P/Invoke, плюс пакеты `System.Management` и `System.Diagnostics.EventLog`.
- **Локализация 100%** - русский и английский, переключение «на лету». При первом запуске язык выбирается по языку Windows.

## 🧰 Стек

- **C# / .NET 8**, **WPF** (собственный лёгкий MVVM)
- WMI (`System.Management`), журнал событий (`System.Diagnostics.EventLog`)
- Win32 P/Invoke, COM через `dynamic`
- Без внешних UI-библиотек

## 🔧 Сборка

> Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download).

```powershell
# Отладочная сборка
dotnet build NakClean.csproj -c Debug

# Portable (один .exe, без установки .NET у пользователя)
dotnet publish NakClean.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -o bin/portable-publish
```

Релизы собираются автоматически: при выпуске версии (метка `vX.Y.Z`, совпадающая с `<Version>` в `NakClean.csproj`) GitHub сам собирает portable-версию и публикует её со списком изменений.

## 💻 Системные требования
